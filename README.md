# Diabetes Prediction System

The Diabetes Prediction System is an AI-based project developed to predict whether a person is likely to have diabetes using Machine Learning techniques.

## Features
- Diabetes prediction using AI/ML
- Fast and accurate prediction results
- Medical data analysis

## Technologies Used
- Python
- Machine Learning
- Google Colab

## Tools & Libraries
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Model Development
The Machine Learning model was developed and trained using Google Colab.

## How to Run the Model Using Google Colab

1. Open Google Colab
2. Upload the `diabetes_prediction.ipynb` file
3. Upload the dataset file if required
4. Run all code cells step-by-step
5. The model will train and display prediction results
